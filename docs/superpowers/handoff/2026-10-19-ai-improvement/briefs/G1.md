# Brief G1: extraction dedupe and quote verification (cloud branch)

Branch: `feat/ai-improvement-cloud` (from main). Worktree, TDD. Read `CLAUDE.md` first. No package changes.
All user-facing copy is Korean (this track adds none). Identifiers and comments are English.

## Goal

Four code-side fixes for the settings extraction, all pure code, no second AI call:
1. Interview extraction receives the work's existing and pending facts (`<known_facts>`) and a system rule not to repeat them.
2. Near-duplicate facts are dropped in code against the work's existing facts (interview, import, chapter check). In import, repeats across chapters of the same job stay exact-only (see out of scope).
3. Evidence quotes (facts, threads, relations) must appear verbatim in the source text; otherwise the item is dropped. Whitespace differences are tolerated and the stored evidence becomes the exact source slice.
4. An interview answer that only says "아직 정하지 않았어요" (any sentence-level variant) skips the AI call and creates no proposals.

Out of scope: same-job cross-chapter near-duplicates in import (`dropRepeatedProposals` in `src/server/imports.ts` keeps its exact `collapseSpaces` key; only wiki facts are checked near-duplicate there). Out of scope (other tracks): name truncation, relation endpoint gating, planted-thread forcing (G2); the shared guard library (GUARDS); harness metrics (HX*).

## Design (do in this order, each step test-first)

1. `src/ai/guards/fact-similarity.ts`: pure `isNearDuplicateFact(a, b)`.
   - `normalizeFactText(s)`: `s.normalize('NFC').toLowerCase().replace(/[^\p{L}\p{N}]/gu, '')`.
   - Equal normalized strings => duplicate.
   - Numbers differ => NOT duplicate: compare the sorted lists of `/\d+/g` matches of the raw strings; if they differ return false.
   - Otherwise Dice coefficient over character bigrams (multiset) of the normalized strings; duplicate when `>= FACT_DUPLICATE_DICE` (export const, 0.8). A string shorter than 2 chars uses itself as its single gram; empty gives 0.
   - Calibrated on full sentences (bare phrases score 0): reworded `종루의 종은 밤마다 떨린다.` vs `종루의 종은 밤마다 떨린다고 한다.` = 0.87 (dup); `서윤은 열일곱 살이다.` vs `서윤은 열여덟 살이다.` = 0.625 and `서윤은 검을 쓴다.` vs `서윤은 검을 쓰지 못한다.` = 0.533 (both below 0.8, not dup). Tests 4 and 6 below use exactly these sentences.
2. `src/ai/guards/evidence-quote.ts`: pure `verifyEvidenceQuote(source, evidence): string | null`.
   - `const quote = evidence.trim()`; empty => null.
   - Try `locateQuote(source, quote)`; if null try `locateQuote(neutralizeTags(source), quote)` (the model saw the neutralized text, where `</x` became `＜/x`; same length, so offsets stay valid).
   - Found => return `source.slice(start, end)` (raw source slice, so whitespace variants are repaired). Not found => null. Case-sensitive, never fuzzy.
3. `src/ai/guards/undecided-answer.ts`: pure `isUndecidedOnlyAnswer(answer): boolean`.
   - Split with `splitSentences`. It splits after every `.!?…` run, so `음... 아직 정하지 않았어요.` becomes `음...` and `아직 정하지 않았어요.`; `음...` normalizes to `음` and is a `filler` (checked by reading `src/lib/korean/sentences.ts`). The implementer still runs `splitSentences('음... 아직 정하지 않았어요.')` once to confirm; if it ever stops splitting there, add `음+` to the marker prefix group instead of changing the test. Normalize each sentence: lowercase, remove `[\s.,!?…~"'“”‘’]`.
   - Class `filler`: `/^(음+|어+|흠+|글쎄요?)$/`. Class `marker`: `/^(음+|어+|글쎄요?|그건|그것은|그게|그냥)*(아직)?(정하지|정해지지|결정하지|생각하지|생각해보지)(않았어요|않았습니다|않았어|않았네요|못했어요|못했습니다)$/`, or `/^(아직)?(모르겠어요|모르겠습니다|몰라요)$/`, or `/^(아직)?정해진(게|것이|건)없(어요|습니다)$/`. Anything else is `other`.
   - Return true only when there is no `other` sentence and at least one `marker`. Conservative on purpose: `결말은 아직 정하지 않았어요.` alone is NOT matched (extraction still runs).
