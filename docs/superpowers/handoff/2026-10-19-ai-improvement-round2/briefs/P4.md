## Goal

Add two rules to the draft system prompt, in Korean (`DRAFT_SYSTEM`) and in the English twin (`DRAFT_CHAPTER_SYSTEM`):

1. Opening: when writing the chapter from the start, show a character's goal or conflict early in the first scene, and do not open with travel or weather description alone.
2. Introductions: a character or proper term that appears in the work for the first time is shown once, in the scene where it appears, through action or dialogue, using only what the wiki and the author's instructions say.

Both rules go in together and are measured together in run R2b (spec section 4). No new code path, flag or signature: two lines in each system prompt, plus the three places that pin the old text.

## Risks

- Rule 2 can turn into explanation (Q3 is already 4 in all four cloud runs, so a drop is the only possible movement). The wording asks for "행동이나 대사로" and "설명문으로 늘어놓지 않는다". If R2b shows Q3 3 with a reviewer quote of a lecture-style intro, loosen rule 2 first.
- Rule 2 can push a model to invent a backstory for a new name (T2 and the "invent nothing" first rule). Mitigated by "작가의 지시와 위키에 있는 내용만"; check T2 counts in R2b.
- Drafts get slightly longer. Cloud drafts were 70 to 82% of target (T3 failures in R1), so no upper-bound risk there; for local qwen en (124.5% of target in R1, bound 130%) it is a small risk, but local runs are out of scope this round.
- Rule 1 could be read as "start with a fight" for quiet chapters. The wording says "목표나 갈등" and bans only a weather or travel-only opening.
- Effects of the two rules cannot be separated in R2b (spec section 4 accepts this; the result document must say so). R2b also contains P5 (also edits this prompt) and P7 (changes reader-sim), so the `reader-novice confused` counts are a proxy only; the Q1 and first-dialogue-offset hand counts from the reviewer are the main signal.
- Three pinned places hold the old text. Missing one fails `speech-off.test.ts`, `draft-chapter.test.ts` or `localize.seam.test.ts`. P5 changes the same three places again, so P5 must start from P4's edited strings.
- Prompt rules are advisory. A model can still open with weather. There is no code guard in this track.
