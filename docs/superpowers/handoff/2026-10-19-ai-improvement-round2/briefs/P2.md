## Goal

Each scene in the beat list (`draft-beats`) gets two optional one-sentence fields:

- `decision`: the decision state of the scene, that is what the character has decided by the end of the scene, or has not decided yet.
- `stake`: what the character expected in the scene and what was lost (or not gained).

`renderBeats` writes them as two labelled lines per scene. When at least one scene has one, it also puts one prose rule above the scene list: do not reverse a stated decision without a reason, and show the expected-and-lost line through gestures or objects, not named emotions. The English run gets the matching system lines and scaffold translations.

Nothing else changes. The one-step (cloud default) draft prompt stays byte-identical. The product never asks for a beat list.

## Interface

```ts
// src/ai/tasks/draft-beats.ts
export type DraftBeats = {
  scenes: {
    place: string
    characters: string[]
    objects: string[]
    sequence: string[]
    /** Decision state: what the character has decided by the end of the scene, or not yet. One sentence. */
    decision?: string
    /** What the character expected in the scene and what was lost or not gained. One sentence. */
    stake?: string
  }[]
}
export const BEATS_STATE_RULE: string
export function renderBeats(beats: DraftBeats): string // unchanged signature
// DraftBeatsSchema: z.ZodType<DraftBeats> (unchanged declaration; scene gains two optional strings)
```

## Risks

- Optional fields can be skipped.
