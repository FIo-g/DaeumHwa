## Goal

When two fact sentences about one card differ only in how a number is written (`스물일곱 살` / `27살`, `서른 닢` / `30닢`, `구층` / `9층`, `두 번` / `2번`), `isNearDuplicateFact` must see them as the same fact. It does so by rewriting Korean number words (수사) that stand directly before a counter into Arabic digits, for both inputs, before any comparison.

Scope is Hangul number words only. English number words (`nineteen`) and fact synonyms stay as they are.

No prompt, schema, UI or Korean copy changes. All new code and comments are English.

Step 1. `src/lib/korean/numbers.ts`. Write `numbers.r2.test.ts` first and watch it fail, then implement. The reference below was prototyped and run against every table in the Tests section in a scratch file outside the repo; the rules are deliberately narrow because the novel's own names and words collide with number words (`한세린` starts with 한, `열쇠` with 열, `이번` is not 2번, `천장` is a ceiling, `일개` is "a mere").

Rules (all in the code below):
1. A number word is converted only when a counter follows it. Counters: `살 층 명 개월 개 번 년 닢 마리 권 시간`, longest first so `개월` wins over `개`. Left boundary: not preceded by a Hangul syllable or a digit.
2. Native numbers (열 스물 스무 서른 마흔 쉰 예순 일흔 여든 아흔, plus 한/하나 두/둘 세/셋 네/넷 다섯 여섯 일곱 여덟 아홉): kind `native` (space before the counter optional) for tens+unit compounds, 스물 스무 서른 마흔 예순 일흔 여든 아흔, 다섯..아홉. Kind `native-short` (a space before the counter is REQUIRED) for 한 두 세 네 열 쉰, so `한층`, `한세린`, `열명` stay as written. `스무` takes no unit; bare 하나 둘 셋 넷 are not read.
3. Sino-Korean numbers (일 이 삼 사 오 육 칠 팔 구, 십 백 천, up to 9999, descending units, no two digit characters in a row): kind `sino` for two or more characters (space optional), `sino-bare` for 십 백 천 alone (space REQUIRED: `천장`, `백성`), `sino-one` for 일..구 alone (NO space, and only the counters `층 년 개월`: so `구층` is 9층, but `이번`, `이명`, `일개`, `이 명령` stay).
4. Digits followed by spaces and a counter are glued (`19 살` becomes `19살`), so the content-word check in `fact-similarity.ts` (which keeps `19살` as one word) sees the same word on both sides.
5. Every converted number loses the space before its counter: `열일곱 살` becomes `17살`.

Reference implementation:

```ts
// Korean number words (수사) to Arabic digits, only where a counter follows. Pure; used by the
// fact near-duplicate check. Narrow on purpose: a name or an ordinary word must not become a number
// (한세린, 열쇠, 이번, 천장, 일개 stay as written). See numbers.r2.test.ts for the pinned cases.

export type NumberKind = 'native' | 'native-short' | 'sino' | 'sino-bare' | 'sino-one'
export type ParsedNumber = { value: number; kind: NumberKind }

const NATIVE_TENS = new Map<string, number>([
  ['열', 10], ['스물', 20], ['스무', 20], ['서른', 30], ['마흔', 40],
  ['쉰', 50], ['예순', 60], ['일흔', 70], ['여든', 80], ['아흔', 90],
])
const NATIVE_UNITS = new Map<string, number>([
  ['하나', 1], ['한', 1], ['둘', 2], ['두', 2], ['셋', 3], ['세', 3], ['넷', 4], ['네', 4],
  ['다섯', 5], ['여섯', 6], ['일곱', 7], ['여덟', 8], ['아홉', 9],
])
/** Bare forms that are never used before a counter (they only follow a tens word: 스물하나). */
const BARE_UNIT_WITHOUT_COUNTER = new Set(['하나', '둘', '셋', '넷'])
/** One-syllable native numbers: converted only with a space before the counter. */
const NATIVE_SHORT = new Set(['열', '쉰', '한', '두', '세', '네'])
const SINO_DIGITS = new Map<string, number>([
  ['일', 1], ['이', 2], ['삼', 3], ['사', 4], ['오', 5], ['육', 6], ['칠', 7], ['팔', 8], ['구', 9],
])
const SINO_UNITS = new Map<string, number>([['십', 10], ['백', 100], ['천', 1000]])
const COUNTERS = ['살', '층', '명', '개월', '개', '번', '년', '닢', '마리', '권', '시간']
/** The only counters a lone Sino digit (구층, 삼년, 오개월) may take. */
const SINO_ONE_COUNTERS = new Set(['층', '년', '개월'])

const alternation = (words: Iterable<string>) =>
  [...words].sort((a, b) => b.length - a.length).join('|')
const NATIVE_PATTERN =
  `(?:${alternation(NATIVE_TENS.keys())})(?:${alternation(NATIVE_UNITS.keys())})?` +
  `|(?:${alternation(NATIVE_UNITS.keys())})`
const SINO_PATTERN = `[${[...SINO_DIGITS.keys(), ...SINO_UNITS.keys()].join('')}]+`
// Native first: 일곱 and 일흔 must not be read as the Sino digit 일.
const NUMBER_BEFORE_COUNTER = new RegExp(
  `(?<![가-힣\\d])(${NATIVE_PATTERN}|${SINO_PATTERN}|\\d+)(\\s*)(${alternation(COUNTERS)})`,
  'gu',
)

function parseNative(word: string): ParsedNumber | null {
  const tens = [...NATIVE_TENS.keys()].find((t) => word.startsWith(t))
  if (tens !== undefined) {
    const base = NATIVE_TENS.get(tens) ?? 0
    const rest = word.slice(tens.length)
    if (rest === '') return { value: base, kind: NATIVE_SHORT.has(tens) ? 'native-short' : 'native' }
    const unit = NATIVE_UNITS.get(rest)
    if (unit === undefined || tens === '스무') return null
    return { value: base + unit, kind: 'native' }
  }
  const unit = NATIVE_UNITS.get(word)
  if (unit === undefined || BARE_UNIT_WITHOUT_COUNTER.has(word)) return null
  return { value: unit, kind: NATIVE_SHORT.has(word) ? 'native-short' : 'native' }
}

function parseSino(word: string): ParsedNumber | null {
  let total = 0
  let digit = 0
  let lastUnit = Infinity
  let afterDigit = false
  for (const ch of word) {
    const d = SINO_DIGITS.get(ch)
    const u = SINO_UNITS.get(ch)
    if (d !== undefined) {
      if (afterDigit) return null // 일이, 삼사: two digits in a row is not one number
      digit = d
      afterDigit = true
    } else if (u !== undefined) {
      if (u >= lastUnit) return null // units must descend: 천 백 십
      total += (digit || 1) * u
      digit = 0
      afterDigit = false
      lastUnit = u
    } else {
      return null
    }
  }
  total += digit
  const kind = [...word].length >= 2 ? 'sino' : SINO_UNITS.has(word) ? 'sino-bare' : 'sino-one'
  return { value: total, kind }
}

/** Value and kind of one number word on its own ("열일곱" is 17), or null when it is not one. */
export function parseNumberWord(word: string): ParsedNumber | null {
  if (word === '') return null
  return parseNative(word) ?? parseSino(word)
}

/**
 * Rewrites each Korean number word that stands directly before a counter as digits glued to the
 * counter ("열일곱 살" -> "17살", "구층" -> "9층"). Digits followed by spaces and a counter are glued
 * too ("19 살" -> "19살"). Everything else is returned as written.
 */
export function koreanNumbersToDigits(text: string): string {
  return text.replace(NUMBER_BEFORE_COUNTER, (match, numeral: string, space: string, counter: string) => {
    if (/^\d+$/.test(numeral)) return space === '' ? match : `${numeral}${counter}`
    const parsed = parseNumberWord(numeral)
    if (parsed === null) return match
    const { kind } = parsed
    if ((kind === 'native-short' || kind === 'sino-bare') && space === '') return match
    if (kind === 'sino-one' && (space !== '' || !SINO_ONE_COUNTERS.has(counter))) return match
    return `${parsed.value}${counter}`
  })
}
```

## Risks

- A false duplicate suppresses a real fact proposal, which is worse than a missed duplicate. Hence the narrow rules (counter required; short natives need a space; lone Sino digits need no space and only `층 년 개월`). The remaining contrived hole: two facts equal except one writes `한 살인 사건` ("a murder case") and the other `1살인 사건` would merge. It needs both sentences to be otherwise identical; accepted.
- Reads can be wrong at the edges: `세 번째` becomes `3번째` and `두 시간대` becomes `2시간대` (consistent on both sides, so harmless for comparison). The converted text is used only inside the comparison; it is never stored or shown, and `change_log` and proposal contents keep the author's or model's original wording.
- The existing content-word check is order dependent for some pairs (see the `검사이다` / `검사다` note). Do not try to fix it here; it is outside the track.
- Old-run comparability: none. The change only adds duplicate matches in new runs.
- Hangul in decomposed form (NFD) would slip past the Hangul lookbehind, so the function applies `normalize('NFC')` before converting.

## Open questions (defaults chosen)

- Counter list: `살 층 명 개월 개 번 년 닢 마리 권 시간`. Left out on purpose because they collide with ordinary words or names after a number: 세 (한세린), 해, 달, 일, 시, 분, 초, 화 (일화, 백화점), 장 (천장), 대 (열대), 매 (열매), 병, 차, 편 (한편). Default: keep this list; widen only with a test that shows the word is safe.
- Attached short natives (`열명`, `한명`, `두번`): default not converted (`한층`, `한번`, `한명회` are real words). Pinned as a documented limit.
- Lone Sino digit with a space (`삼 층`, `삼 년 전`): default not converted (`이 층` is "this floor"). Pinned as a documented limit.
- Digits glued to the counter (`19 살` -> `19살`): default yes; without it `열아홉 살` and `19 살` would still differ in the content-word step.
- Numbers with no counter (`나이는 열일곱이다`, `스물일곱쯤`): default not read. Pinned. A broader rule would turn `열쇠`, `한` and `이` into numbers.
- Export from `src/lib/korean/index.ts`: default no.
- Reuse in `numeric-facts.ts` (`열일곱 살` is invisible to the age check today): default no; that belongs to P13 and is not in the P15 row.
