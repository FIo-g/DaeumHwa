## 0. 먼저 알아둘 것

- **5화 합계가 아니라 1화 합계다.** "5화 평균", "5화 TTCW"는 1화 한 편으로 냈다. 표본이 하나라서 모델 사이의 순위 근거로는 약하다.
- **문체 제안과 연재 방향 조언은 호출 기록이 없다.** 설계서 6.3에 따라 문체 제안은 2화 뒤, 연재 방향 조언은 2화부터 돈다. 이 실행에는 해당 호출이 없어 채점하지 않는다. `wiki-final.json`의 문체 카드 1건은 작가가 준비 단계에서 넣은 것(`createdByType: author`)이다.
- **하네스 지표 두 가지는 이 판에서 믿을 수 없다.**
  - `foreignRuns`는 한국어판에서 라틴 문자 4자 이상만 센다(`eval/novel/metrics.ts`의 `LATIN_RUN`). 한자는 잡지 못한다. 이 실행의 `foreignRuns`는 `[]`인데 최종 본문에는 한자가 남아 있다.
  - `hangulLeft`(66,661)는 호출 시스템과 프롬프트의 한글 글자 수 합이다. 한국어판은 프롬프트가 한국어라서 값이 의미가 없다. 영어판에서 한국어가 새는지 볼 때만 쓴다.
- 증거가 없는 항목은 점수를 매기지 않고 "근거 없음"이라고 적었다.

| `깃을` → `깃을` | 틀림. 바뀌는 게 없고 이유(`'깃'은 존재하지 않는 단어`)도 거짓. 제품이 걸러 화면에는 5건만 나옴 |
| `'감시관' 자样的 배지` → `'감시관'이라고 적힌 배지` | 맞음 |
| `어머니의 자기가` → `어머니의 자필이` | 맞음 |
| `봉투를 왼손으로 바꿨다` → `옮겼다` | 문체 변경(오류 아님). 작가가 거절 |

- 맞는 제안: 서로 다른 3건 / 6건. 중복을 맞는 것으로 치면 4/6. 작가의 수용은 4건(0, 1, 2, 4번), 거절 1건(3번)이다. 4층 이상은 중복 수용이라 효과는 1회분이다.
- 놓친 것: `원장嬷嬷가`(7행), 67행 `4층이상은`, `종잇질감`, `검 날은`, `걸러 놓고`, `달아 있었다`. 한자를 놓친 것이 가장 크다.
- **운영.** 1회차(028)는 1,217.8초 뒤 `AI 응답이 너무 길어 중간에 끊겼습니다.`(출력 상한 32,000 토큰)로 실패했고, 2회차(029)가 1,497.4초에 성공했다. 제안 6건에 출력 18,899 토큰, 호출 둘 다 120초 제한 초과. 한 단계가 전체 모델 시간의 29.9%(2,715초)를 먹었다.
- **개선 후보.** (a) 본문을 3등분해 따로 교정한다(출력 한도와 시간 모두 줄어든다). (b) 같은 `quote`는 중복을 합치고 모든 출현 위치에 적용한다. (c) 한자와 같은 외국 문자는 코드로 먼저 잡는다. (d) 교정 단계의 effort를 낮춘다. 기대 효과: 호출 시간과 실패 감소, 잔여 오류 약 2건 감소, T5 문제 제거.

### 3.6 독자 시뮬레이션 (4점)

근거: `calls/032`, `reader/01.json`.

- 페르소나 4명 평점 3 / 4 / 2 / 4, 이탈 위험 medium / low / high / low.
- 인용 6건이 모두 본문에 있다(글자 단위 확인).
- 근거에 닿은 조언:
  - 반복: `내려가세요` 3회, 계단 오르내림 3회, 왼손/오른손 반복 → 본문과 맞다(`내려가세요` 대사 3회, 손 언급 37회).
  - `마치 무언가를 삼키려다 삼키지 못하는 것처럼`이 해석을 대신 말한다 → 215행과 맞다.
  - 열쇠의 `흠집` 디테일이 좋은 씨앗이라는 평가 → 141행과 맞다.
- 쓸모: 분량 줄이기, 비유를 하나로 줄이기, 등정 장면 압축 같은 실행 가능한 수정 제안이다.
- 아쉬운 점:
  - `왼손-오른손 반복 10번 넘게`는 실제(37회)보다 적게 셌다.
  - 요약의 `대문 밖에서 뒤를 돌아보지 않은 채 9층을 올려다본다`는 본문(273~277행: 불빛을 한 번 보고 고개를 돌린다)과 다르다. `도윤서(28세)`는 본문의 나이를 따랐다.
  - 4명 모두 `嬷嬷`, 철문 통과 누락, 재등정 논리를 지적하지 않았다.
- 4점.
